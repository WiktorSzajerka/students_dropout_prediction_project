# students_dropout_prediction_project

Project Objectives
• to create a model that classifies students into three groups at the end of their studies
 (dropped, enrolled, graduated),
• to compare the effectiveness of three models designed for processing
tabular data: TabNet, ARM-Net, and SAINT
• to analyze the importance of the features considered in the prediction to ensure
the model’s interpretability.


Models for experiment are based on following repositories:
https://github.com/dreamquark-ai/tabnet
https://github.com/nusdbsystem/ARM-Net/tree/uci
https://github.com/somepago/saint
